  • Optimization: The exercise requires you to optimize this system. This means:

    • Responsiveness: The game needs to react quickly to terrain changes. A sudden mountain formation shouldn't cause a massive resource spike.
    • Scalability: The system should be able to handle a wide range of terrain types and changes without performance issues.

In essence, Exercise 3 is about creating a system that feels alive and responsive by intelligently adjusting resource production based on the environment.
